# Kept or Released by Covenant

A Christian writing project exploring covenant, freedom, surrender, and the difference between being held by God and being released into His purpose.

## Live Website
https://brad-hobbswd.github.io/kept-released-covenant/

## Project Overview
Kept or Released by Covenant explores the difference between covenant, culture, and tradition through thoughtful writing and biblical reflection.
